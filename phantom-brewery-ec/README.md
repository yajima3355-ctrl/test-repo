# Phantom Brewery EC - 静謐の中に宿る、和の余韻

## プロジェクト概要

Phantom BreweryのECサイトリニューアルプロジェクトです。ブランドコンセプト「静謐の中に宿る、和の余韻」に基づき、高級感ある世界観を表現したeコマースサイトを構築します。

## ブランドコンセプト

### コンセプト名
**「静謐の中に宿る、和の余韻」**

### キーワード
- **凛** - 飾り立てない美しさ
- **粋** - 現代的な知性
- **和とモダンの融合** - 伝統と革新の調和

### ブランドコピー
- 「和を、纏う。」
- 「語られぬ美が、ここにある。」
- 「日本の心、そのひとしずく。」

## デザインシステム

### カラーパレット
- **ベースカラー**: インク (#1a1a1a)、ダークブルー (#1e3a5f)、パステルホワイト (#fafafa)
- **アクセント**: 金箔 (#d4af37)、朱 (#c5282f)

### タイポグラフィ
- **英字**: Avenir Light, Helvetica Neue
- **和文**: Yu Mingchao、Ko Mingchao、Noto Serif JP

### レイアウト・演出
- TOPビジュアル: 四季の情景+酒器に注がれる一滴
- カラー演出: モノクロと金のコントラスト

## 技術仕様

### フロントエンド
- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (ES6+)
- レスポンシブデザイン

### デザイン原則
- ミニマリズムと和の美学の融合
- 高級感のある視覚表現
- ユーザビリティを重視したUX設計
