# Stay@Link Brochure - Print Specifications

## File Specifications

### Source Files
- **Format**: Adobe Illustrator (.ai)
- **Version**: CS6 or later
- **Color Mode**: CMYK
- **Resolution**: 350 DPI
- **Artboard Size**: 420mm × 297mm (A3 Landscape)

### Print Files
- **Format**: PDF/X-1a
- **Color Space**: CMYK
- **Resolution**: 350 DPI
- **Bleed**: 3mm on all sides
- **Crop Marks**: Included
- **Registration Marks**: Included

## Color Specifications

### CMYK Values
- **Deep Blue**: C:85 M:65 Y:0 K:45
- **Bright Blue**: C:70 M:45 Y:0 K:0
- **Light Blue**: C:55 M:25 Y:0 K:0
- **White**: C:0 M:0 Y:0 K:0
- **Black**: C:0 M:0 Y:0 K:100

### Spot Colors (if needed)
- **Pantone 286 C**: Deep Blue alternative
- **Pantone 3005 C**: Bright Blue alternative

## Typography Specifications

### Font Requirements
- **Primary**: Helvetica Neue (or Arial)
- **Weights**: Regular, Bold
- **Embedding**: All fonts must be embedded
- **Outlining**: Text can be outlined for compatibility

### Font Sizes
- **Main Headlines**: 24-28pt
- **Section Titles**: 18-20pt
- **Body Text**: 12-14pt
- **Captions**: 10pt
- **Small Text**: 8pt

## Layout Specifications

### Margins and Bleed
- **Safe Area**: 30mm from all edges
- **Bleed Area**: 3mm beyond trim size
- **Total Artboard**: 426mm × 303mm (including bleed)

### Grid System
- **Columns**: 4 columns
- **Gutter**: 10mm between columns
- **Baseline Grid**: 6pt baseline

## Image Specifications

### Resolution Requirements
- **Print Resolution**: 350 DPI minimum
- **Web Resolution**: 72 DPI (for preview)
- **Format**: TIFF or high-quality JPEG
- **Color Mode**: CMYK for print, RGB for web

### Image Guidelines
- **Compression**: Minimal compression for print
- **Sharpening**: Apply appropriate sharpening
- **Color Profile**: Embed ICC profiles
- **Rights**: Ensure commercial use rights

## Print Production Notes

### Paper Specifications
- **Weight**: 150-200gsm
- **Finish**: Glossy or matte (client preference)
- **Size**: A3 (297mm × 420mm)

### Printing Method
- **Process**: Offset or digital printing
- **Color Matching**: Use provided color specifications
- **Proofing**: Request color proof before final print

### Quality Control
- **Registration**: Check color registration
- **Sharpness**: Verify image sharpness
- **Color Accuracy**: Compare to color specifications
- **Text Readability**: Ensure all text is legible

- [ ] Front side PDF (PDF/X-1a)
- [ ] Back side PDF (PDF/X-1a)

- `StayLink_Brochure_Front.ai`
- `StayLink_Brochure_Back.ai`

- `StayLink_Brochure_Back.pdf`
- `StayLink_StyleGuide.pdf`

### Pre-flight Checklist
- [ ] All fonts embedded or outlined
- [ ] Images linked and embedded
- [ ] Color mode set to CMYK
- [ ] Bleed area properly set
- [ ] Crop marks included
- [ ] Resolution appropriate for print
- [ ] No RGB colors in CMYK file
- [ ] All text converted to outlines (if required)

## Network Printing Specifications (Graphic-sha)

### File Requirements
- **Format**: PDF/X-1a
- **Color Space**: CMYK
- **Resolution**: 350 DPI
- **Bleed**: 3mm
- **Crop Marks**: Required
- **File Size**: Under 100MB

### Upload Specifications
- **Method**: Web upload
- **Compression**: ZIP file if multiple files
- **Naming**: Clear, descriptive filenames
- **Proof**: Request digital proof

### Quality Standards
- **Color Accuracy**: ±5% tolerance
- **Registration**: ±0.1mm tolerance
- **Sharpness**: Clear, crisp images
- **Text**: No broken or missing characters
