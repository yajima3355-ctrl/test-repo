# Stay@Link Brochure Style Guide

## Brand Identity

### Logo Usage
- **Product Name**: Stay@Link (ステイ・リンク)
- **Logo Symbol**: The "@" symbol represents digital/network connectivity
- **Typography**: Bold, modern sans-serif font
- **Color**: Deep blue (#1E3A8A) for primary text

### Color Palette

#### Primary Colors
- **Deep Blue**: #1E3A8A (Primary brand color - trust, reliability)
- **Bright Blue**: #3B82F6 (Secondary - digital elements, CTAs)
- **Light Blue**: #60A5FA (Accent - highlights, interactive elements)

#### Supporting Colors
- **White**: #FFFFFF (Background, clean space)
- **Light Gray**: #F8FAFC (Card backgrounds, subtle sections)
- **Medium Gray**: #6B7280 (Supporting text, secondary information)
- **Dark Gray**: #1F2937 (High contrast text)

### Typography

#### Headlines
- **Font**: Helvetica Bold / Arial Bold
- **Size**: 24-28px (main headlines), 18-20px (section titles)
- **Color**: #1E3A8A (Deep Blue)
- **Line Height**: 1.2

#### Body Text
- **Font**: Helvetica Regular / Arial Regular
- **Size**: 14px (main text), 12px (supporting text), 10px (captions)
- **Color**: #1E3A8A (primary), #6B7280 (secondary)
- **Line Height**: 1.4

#### UI Elements
- **Font**: Monospace (for technical specifications)
- **Size**: 12px
- **Color**: #64748B

### Layout Specifications

#### A3 Landscape Format
- **Dimensions**: 420mm × 297mm
- **Margins**: 30mm (all sides)
- **Grid System**: 4-column grid for content organization
- **Bleed**: 3mm (for print production)

#### Spacing System
- **Large Spacing**: 20mm (section breaks)
- **Medium Spacing**: 15mm (card spacing)
- **Small Spacing**: 8mm (element spacing)
- **Micro Spacing**: 3mm (text spacing)

### Visual Elements

#### Icons
- **Style**: Simple, flat design
- **Size**: 30-40px (feature icons), 20px (small icons)
- **Color**: #3B82F6 (primary), #60A5FA (accent)
- **Background**: Circular, 50% larger than icon

#### Cards and Containers
- **Background**: rgba(255, 255, 255, 0.15) with backdrop blur
- **Border**: 1px solid rgba(255, 255, 255, 0.2)
- **Border Radius**: 8-12px
- **Shadow**: Subtle drop shadow for depth

#### Network Graphics
- **Style**: Flowing lines, connection nodes
- **Color**: #60A5FA with transparency
- **Animation**: Subtle flow animation (optional)
- **Opacity**: 0.1-0.2 for background elements

### Content Guidelines

#### Front Side Structure
1. **Hero Section** (20% height)
   - Logo + Catchphrase
   - Network background graphics
   
2. **Benefits Section** (40% height)
   - 4 key benefits in 2×2 grid
   - Icon + title + description format
   
3. **UI Showcase** (30% height)
   - Dashboard mockups
   - Key metrics display
   
4. **CTA Section** (10% height)
   - Contact button
   - Call-to-action

#### Back Side Structure
1. **Header** (15% height)
   - System overview title
   
2. **Features** (35% height)
   - 4 feature cards in horizontal layout
   
3. **Workflow** (25% height)
   - Step-by-step process flow
   
4. **Integration** (15% height)
   - Compatible systems grid
   
5. **Benefits** (10% height)
   - ROI metrics and advantages

### Print Specifications

#### File Formats
- **Source**: Adobe Illustrator (.ai)
- **Print**: PDF/X-1a (CMYK)
- **Resolution**: 350 DPI
- **Color Space**: CMYK
- **Bleed**: 3mm
- **Crop Marks**: Included

#### Font Requirements
- **Embedded**: All fonts must be embedded or outlined
- **Fallbacks**: Helvetica/Arial system fonts as backup
- **License**: Ensure commercial use rights

#### Image Requirements
- **Format**: High-resolution PNG/JPG
- **Resolution**: 350 DPI minimum
- **Color**: CMYK conversion
- **Rights**: Commercial use clearance

### Usage Guidelines

#### Do's
- Use blue-based color scheme consistently
- Maintain clean, modern aesthetic
- Emphasize connectivity and integration
- Include clear call-to-action elements
- Use professional, trustworthy tone

#### Don'ts
- Don't use conflicting color schemes
- Avoid cluttered layouts
- Don't use low-resolution images
- Avoid complex animations in print
- Don't compromise readability for style

### Technical Notes

#### Browser Compatibility
- Modern browsers (Chrome, Firefox, Safari, Edge)
- CSS Grid and Flexbox support required
- Backdrop-filter support recommended

#### Print Optimization
- High contrast for readability
- Sufficient white space
- Clear hierarchy
- Print-friendly color combinations

#### Accessibility
- Sufficient color contrast ratios
- Clear typography hierarchy
- Logical reading order
- Alternative text for images

### File Organization

#### Deliverables
- `staylink_brochure_front.ai` - Front side Illustrator file
- `staylink_brochure_back.ai` - Back side Illustrator file
- `staylink_brochure_front.pdf` - Front side print PDF
- `staylink_brochure_back.pdf` - Back side print PDF
- `staylink_style_guide.pdf` - Complete style guide
- `fonts/` - Font files used
- `images/` - High-resolution images
- `logos/` - Logo variations and formats

#### Naming Convention
- Files: `staylink_[element]_[side].[extension]`
- Layers: `[section]_[element]_[version]`
- Colors: `StayLink_[color]_[usage]`
- Fonts: `StayLink_[weight]_[size]`
