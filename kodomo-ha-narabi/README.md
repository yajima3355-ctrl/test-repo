# 子ども歯並びまるわかりサイト

兵庫県灘区・六甲周辺のえぐさ歯科クリニックが運営する、子どもの矯正治療に特化したサテライトサイトです。

## サイト概要

このサイトは、子どもの歯並びや矯正治療について、保護者の方にわかりやすくお伝えすることを目的としています。保育園のような親しみやすい雰囲気で、専門性を身近に感じてもらえるデザインを採用しています。

### 主な特徴

- **温かいデザイン**: パステルカラー（水色・黄色系）を中心とした親しみやすいデザイン
- **地域性の表現**: 六甲の地域性を活かした背景変化（星空→朝焼け→山並み→まち→海）
- **インタラクティブな要素**: パララックス効果、アニメーション、タブ切り替えなど
- **レスポンシブ対応**: モバイル・タブレット・デスクトップに対応
- **アクセシビリティ**: 読みやすいフォントサイズと行間、適切なコントラスト

## 技術仕様

### 使用技術
- **HTML5**: セマンティックなマークアップ
- **CSS3**: モダンなスタイリングとアニメーション
- **JavaScript (ES6+)**: インタラクティブな機能
- **Google Fonts**: Zen Maru Gothic, Noto Sans JP

### デザインシステム
- **最大幅**: 1300px
- **カラーパレット**: パステルカラー中心
- **フォント**: Google Fonts使用（OS依存フォント不使用）
- **レスポンシブ**: モバイルファーストアプローチ
